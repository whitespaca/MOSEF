# BAR-001 - Divisor coverage does not imply order separation

Status: `PROVED` after bounded falsification and independent adversarial
review.

## Definitions

Let \(\Delta\) be a finite set of positive integers. For a positive order
\(r\), define its **divisibility signature**

\[
\Sigma_\Delta(r)=\{d\in\Delta:r\mid d\}.
\]

The family has the **\(n\)-divisor property** when
\(\Sigma_\Delta(r)\ne\varnothing\) for every \(1\le r\le n\).

For an order profile \(R=(r_1,\ldots,r_k)\), \(k\ge2\), a candidate
\(d\in\Delta\) is an **order separator** when the set

\[
\{i:r_i\mid d\}
\]

is nonempty and proper. The family has the **distinct-order
\(n\)-separator property** when it separates every profile drawn from
\(\{1,\ldots,n\}\) that contains at least two distinct order values.

A positive difference family is

\[
\Delta^+(S,T)=\{s-t:s\in S,\ t\in T,\ s>t\}
\]

for finite positive-integer sets \(S,T\). Allowing absolute nonzero
values for every retained nonzero directed difference gives the same
divisibility signatures, because divisibility is invariant under sign. It
does not justify discarding a negative directed difference, and zero is
excluded.

## Lemma - exact signature characterization

\(\Delta\) separates a profile \(R=(r_1,\ldots,r_k)\) if and only if the
signatures \(\Sigma_\Delta(r_i)\) are not all equal.

### Proof

If \(d\) separates the profile, choose a hit index \(i\) and a miss index
\(j\). Then \(d\in\Sigma_\Delta(r_i)\) but
\(d\notin\Sigma_\Delta(r_j)\), so the signatures differ.

Conversely, if two signatures differ, their symmetric difference contains
some \(d\). That candidate is divisible by one associated order and not the
other. Its profile support is therefore nonempty and proper. \(\square\)

## Corollary - the missing condition

\(\Delta\) has the distinct-order \(n\)-separator property if and only if
the map

\[
r\longmapsto\Sigma_\Delta(r)
\]

is injective on \(\{1,\ldots,n\}\).

The \(n\)-divisor property requires only that all these signatures be
nonempty. Nonemptiness does not imply injectivity. Equal-order profiles remain
impossible for every support-only family, as already recorded by the
prime-power obstruction in M2.

## BAR-001 statement

The \(n\)-divisor property, including when realized by a positive difference
family, does not imply the distinct-order \(n\)-separator property.
Furthermore, every family with both properties satisfies

\[
|\Delta|\ge \left\lceil\log_2(n+1)\right\rceil.
\]

If \(\Delta=\Delta^+(S,T)\), then

\[
|S||T|\ge|\Delta|\ge\left\lceil\log_2(n+1)\right\rceil.
\]

### Counterexample

For \(n=2\), take \(S=\{3\}\), \(T=\{1\}\), and
\(\Delta^+(S,T)=\{2\}\). Both \(1\) and \(2\) divide the unique difference,
so the family has the \(2\)-divisor property. But

\[
\Sigma_\Delta(1)=\Sigma_\Delta(2)=\{2\},
\]

so the order profile \((1,2)\) is not separated.

This failure occurs in an actual multiplicative-order candidate. For
\(N=6\) and \(g=5\),

\[
\operatorname{ord}_2(5)=1,\qquad
\operatorname{ord}_3(5)=2,
\]

but

\[
\gcd(5^2-1,6)=6.
\]

Thus divisor coverage produces a simultaneous collision rather than a
factor. The smallest odd example is \(N=15\), \(g=4\), with orders \(1\)
modulo \(3\) and \(2\) modulo \(5\).

### Counting lower bound

If the family has both properties, the \(n\) orders have distinct nonempty
signatures. A family of \(k=|\Delta|\) candidates has only \(2^k-1\)
nonempty subsets, so \(n\le2^k-1\). Rearranging proves the first bound.
Every positive difference is generated by a pair in \(S\times T\), hence
\(|\Delta|\le|S||T|\), which proves the second. \(\square\)

## A sufficient but non-polynomial construction

Put \(h=\lceil\sqrt n\rceil\), and define

\[
S=\{1+ih:1\le i\le h\},\qquad
T=\{1+j:0\le j<h\}.
\]

The positive differences are exactly

\[
\{ih-j:1\le i\le h,\ 0\le j<h\}=\{1,\ldots,h^2\}.
\]

For distinct \(r<s\le n\), the difference \(d=r\) is divisible by \(r\)
but not by \(s\). Hence this factorization-independent difference family
satisfies the stronger separator property. It uses
\(|S||T|=h^2=\Theta(n)\) candidate pairs. When \(n\) is comparable to an
unknown group order of magnitude exponential in the binary input length,
enumerating the pairs is exponential and supplies no polynomial-time POSF.

## Source-scope audit

Umans and Wang's Definition 3.1 and Conjectures 3.2--3.3 concern divisor
coverage. Theorem 5.2's abstract \(A_i\) framework combines coverage with
fast interval products and factorization of each \(A_i\); prefactored
differences instantiate that framework in Theorem 5.5. It does not use
multiplicative orders and does not claim that coverage implies order
separation. BAR-001 therefore does not refute their conditional theorems; it
blocks only an attempted transfer of their coverage premise into MOSEF
without the injective-signature strengthening.

## Complexity and recognition limits

- Computing all signatures from explicit \(\Delta\) and a supplied order
  profile is polynomial in the total bit length of those explicit inputs.
- The profile itself is factor dependent in MOSEF and is used only by the
  analysis oracle, not a constructor.
- The counting bound is for explicit candidates. It does not rule out compact
  batch evaluation or stronger algebraic structure.
- No general factoring lower bound follows.

2. Enumerate small divisor covers and minimize failures of signature

3. Verify the \(N=6\) and smallest odd simultaneous collisions using exact

4. Check the sufficient square difference construction for every bounded
   \(n\).
5. Differentially check selected cover/profile outcomes in Python, Rust, and
